ETAPA 01 / PRIMEIRO ACESSO
✦

Vamos ativar seu Naples Studios.

Defina uma senha administrativa. Ela protege as configurações de integração mesmo quando outra pessoa estiver conectada pelo Discord. A configuração inicial é permitida somente no computador onde o servidor está executando.

Quando o acesso não é direto pelo localhost, o código temporário aparece no terminal em que você iniciou o Naples Studios.
↳ A senha não é enviada ao Discord ou Roblox. Uma chave de criptografia é gerada automaticamente no servidor.

ETAPA 03

Roblox Open Cloud

Configure uma vez; todos os envios usarão este destino.

ASSETS API
Ainda não configuradaAo colar sua API Key, o Naples Studios consulta a identidade autorizada pelo Roblox.
O ID de usuário será detectado automaticamente. Para grupo com vários destinos, informe o ID apenas aqui.
Evita publicar por engano em destinos diferentes. A API Key ainda precisa ter permissão Roblox válida.
Crie a chave no Roblox Creator Hub ↗ com acesso a Assets (Read e Write).
